📊 **My Sales Performance Dashboard Project | Power BI**

I'm excited to share my Sales Performance Analysis Dashboard, a beginner data analytics project built using Power BI and CSV data.

**What I worked on:**
- Cleaned and transformed sales data using Power Query
- Created KPIs to track sales, profit and order performance
- Analyzed monthly sales trends
- Compared product categories and regional performance
- Built interactive visualizations and filters

**Tools Used:** Power BI | Power Query | DAX | CSV

**What I learned:** This project helped me understand how to transform raw data into meaningful business insights and present them through an interactive dashboard.
